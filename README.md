# 🎶 BunkaMix

文化祭・学園祭のダンス発表や演劇、発表会で使う音源を、**初心者でも迷わず編集できる**ブラウザ専用の音声編集アプリです。

サーバーは一切使いません。ブラウザの中だけで「音源の取り込み → 並び替え → 効果音の追加 → 曲間の調整 → 本番用の確認 → CD用WAVの書き出し」まで完結します。

> 「本格的なDAW」ではなく、「文化祭の音源を素早く作ることに特化した、簡単な音声編集ソフト」として設計しています。

## BunkaMixとは

文化祭のダンス・演劇・発表会などで使う音源づくりは、本来なら音楽編集ソフトの知識が必要になりがちです。
BunkaMixは、そういった知識がない中高生でも、

- MP3をドラッグ＆ドロップするだけで取り込み
- タイムライン上で曲順を入れ替え
- 効果音を好きな位置に配置
- 曲と曲の間に無音時間やクロスフェードを設定
- 本番前に「本番モード」で確認
- ボタン1つでCD用の音源（WAV）を書き出す

という一連の作業を、直感的な操作だけで行えるように作られています。

## 主な機能

| # | 機能 | 内容 |
|---|------|------|
| 1 | MP3ドラッグ＆ドロップ | MP3/WAV/OGG/M4A/AAC/WebMに対応。複数ファイルを同時に取り込めます |
| 2 | 横長タイムライン | ズームイン・アウト、横スクロール、再生位置ラインに対応 |
| 3 | BGM・効果音トラック | 🎵BGMトラックと🔊効果音トラックを分けて管理 |
| 4 | 効果音追加 | 好きな位置へドラッグ配置。移動・削除・複製・音量・フェード・トリミングが可能 |
| 5 | 波形表示 | Canvasで波形を描画。ズームしても崩れません |
| 6 | カット・分割・削除 | 再生ヘッド位置での分割、削除、複製に対応。Undo/Redoあり |
| 7 | フェード | クリップごとにフェードイン・フェードアウトを秒数で設定 |
| 8 | クロスフェード | 0.5〜5秒から選んで、曲同士を自然につなげる |
| 9 | 曲間の無音時間 | 0〜10秒または自由入力で、曲と曲の間に無音を挿入 |
| 10 | 音量調整 | クリップ単位・トラック単位・マスターの音量をdBで調整。ミュートあり |
| 11 | 音量自動調整 | 曲ごとの音量差を自動でならし、「1曲だけ極端に大きい」を防止 |
| 12 | セットリスト | 左側パネルで曲順を一覧表示。ドラッグで並べ替え可能 |
| 13 | マーカー | ⭐🔊💃🎬🎤など、タイムライン上に目印を配置してジャンプ |
| 14 | 本番モード | 誤操作しにくい、シンプルな大画面の再生専用モード |
| 15 | カウントダウン | 本番モードで「5, 4, 3, 2, 1, START」のカウントダウン表示 |
| 16 | プロジェクト保存 | 独自形式 `.bunkamix` に、音声データも含めて保存 |
| 17 | 自動バックアップ | IndexedDBへ自動保存し、次回起動時に復元を提案 |
| 18 | CD用WAV書き出し | 44,100Hz / 16bit / ステレオのWAVをワンクリックで生成 |
| 19 | 曲ごとの書き出し | セットリストの曲を個別ファイル、またはZIPでまとめて書き出し |
| 20 | キーボードショートカット | Space / S / Delete / Ctrl+Z・Y・S・O / Home / End など |

## 必要環境

- [Node.js](https://nodejs.org/) 18以上（20推奨）
- npm（Node.jsに同梱されています）
- モダンブラウザ（Chrome / Edge / Firefox の最新版を推奨）

## インストール方法

1. このリポジトリをダウンロードするか、`git clone` してください。
2. プロジェクトのフォルダに移動し、依存パッケージをインストールします。

```bash
npm install
```

## 開発方法（ローカルで動かす）

以下のコマンドで開発用サーバーが起動します。表示されたURL（通常は `http://localhost:5173`）をブラウザで開いてください。

```bash
npm run dev
```

ファイルを編集すると、ブラウザが自動的に更新されます。

## ビルド方法

本番用の静的ファイルを生成するには、以下を実行します。

```bash
npm run build
```

`dist` フォルダに、そのままどこへでも配置できる完成品が出力されます。手元で確認したい場合は次のコマンドでプレビューできます。

```bash
npm run preview
```

## GitHub Pagesへの公開方法

このリポジトリには、GitHub Actionsによる自動デプロイ設定（`.github/workflows/deploy-pages.yml`）が含まれています。以下の手順で公開できます。

1. このリポジトリをGitHubへpushします。
2. GitHubのリポジトリページで **Settings → Pages** を開きます。
3. 「Build and deployment」の「Source」を **GitHub Actions** に設定します。
4. `main` ブランチへpushすると、自動的にビルドとデプロイが実行されます。
5. しばらく待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。

> Viteの `base` 設定は、GitHub Actions側で自動的にリポジトリのサブパスへ調整されるようになっているため、リポジトリ名を変更しても手動で設定を書き換える必要はありません。

## 使い方

1. **音源を追加する**：画面中央（またはタイムライン）へMP3などをドラッグ＆ドロップするか、「🎵 音源を追加」ボタンから選択します。
2. **曲順を整える**：左側の「セットリスト」パネルで曲をドラッグして並べ替えます。タイムライン上でも直接ドラッグで移動できます。
3. **曲を編集する**：クリップを選択し、上部のタイムラインツールバーから「✂ 分割」「🗑 削除」「📋 複製」やフェイン・フェードアウト、音量を設定します。
4. **曲間を調整する**：クリップを選んで「クロスフェード」または「曲間の無音」を選び、「曲間に適用」ボタンを押します。
5. **効果音を配置する**：効果音ファイルを🔊効果音トラックへドラッグ＆ドロップします。
6. **マーカーを付ける**：再生位置を合わせてから「📍 マーカー追加」ボタンを押し、種類を選びます。
7. **保存する**：「💾 保存」または「💾 名前を付けて保存」で `.bunkamix` ファイルとしてダウンロードされます。編集中は自動的にブラウザ内へバックアップも保存されます。
8. **本番前に確認する**：「🎤 本番モード」で、大きな文字のシンプルな画面から再生・カウントダウンを確認できます。
9. **音源を書き出す**：「💿 書き出し」から、CD用のWAV、または曲ごとのWAV（個別 or ZIP）を選んでダウンロードします。

### キーボードショートカット

| キー | 動作 |
|------|------|
| Space | 再生 / 一時停止 |
| S | 選択中クリップを再生ヘッド位置で分割 |
| Delete | 選択中クリップを削除 |
| Ctrl + Z | 元に戻す |
| Ctrl + Y | やり直す |
| Ctrl + S | 保存 |
| Ctrl + O | プロジェクトを開く |
| Home / End | タイムラインの先頭・末尾へ移動 |
| + / − | タイムラインの拡大・縮小 |

アプリ内の「❓ ヘルプ」ボタンからも確認できます。

## CD用WAVについて

「💿 書き出し」→「💿 CD用WAVを書き出す」を押すと、プロジェクト全体を **44,100Hz / 16bit / ステレオ** のWAVファイルとして1本にまとめて書き出します。細かい設定は不要です。文化祭当日の音響機材（CDプレイヤーやミキサーなど）でそのまま再生できる形式です。

## 対応ブラウザ

Web Audio API・Canvas API・IndexedDBを使用しているため、最新版の **Google Chrome** または **Microsoft Edge** を推奨します。Firefoxでも動作しますが、音声形式（特にAAC/M4A）の対応状況はブラウザによって異なります。

## 注意事項

- プロジェクトファイル（`.bunkamix`）には音声データ自体も可能な限り含めて保存されるため、曲数や曲の長さによってはファイルサイズが大きくなります。
- ブラウザのタブを閉じる・リロードする前に、なるべく「💾 保存」を行ってください（自動バックアップはブラウザ内のみに保存されるため、別の端末やブラウザには引き継がれません）。
- 音量自動調整は簡易的なラウドネス推定です。実際の会場での聞こえ方は、可能であれば当日に音響機材で確認してください。
